## Turn Pages on (phone)
1. Open this link:
https://github.com/910pro/910pro-agent/settings/pages
2. Under Build and deployment → Source pick **Deploy from a branch**
3. Branch: **main**
4. Folder: **/docs**
5. Save

Wait about a minute then open the live page.
